# Сервис управления рассылками (Mailing Service)

## Описание проекта

Веб-приложение на Django для создания и управления email-рассылками. Пользователи могут добавлять клиентов, создавать сообщения, планировать рассылки и отслеживать статистику отправок.

## Функциональность

### 1. Управление клиентами
- Добавление, просмотр, редактирование и удаление получателей рассылок
- Каждый клиент содержит: email, ФИО, комментарий
- Клиенты привязаны к создавшему их пользователю

### 2. Управление сообщениями
- Создание и редактирование шаблонов писем
- Каждое сообщение содержит: тему, текст письма
- Сообщения привязаны к пользователю

### 3. Управление рассылками
- Создание рассылок с выбором сообщения и получателей
- Планирование времени отправки (дата начала и окончания)
- Автоматическое определение статуса: создана, запущена, завершена
- Возможность ручного запуска рассылки

### 4. Отправка писем
- Отправка писем всем выбранным получателям
- Сохранение истории каждой попытки отправки
- Отслеживание успешных и неудачных отправок

### 5. Статистика
- Общее количество рассылок
- Количество активных рассылок
- Количество уникальных получателей
- Детальная статистика по каждой рассылке

### 6. Пользователи и права доступа
- Регистрация и авторизация по email
- Разделение на обычных пользователей и менеджеров
- Менеджеры видят все рассылки и могут блокировать пользователей
- Обычные пользователи видят только свои данные

### 7. Кэширование
- Кэширование главной страницы
- Кэширование списков для уменьшения нагрузки на БД
- Автоматическая очистка кэша при изменении данных

## Технологии

- Python 3.13
- Django 6.0
- PostgreSQL
- Redis (для кэширования)
- Bootstrap 5
- Git

## Установка и запуск

### 1. Клонирование репозитория
git clone <ссылка на твой репозиторий>
cd PythonProject_Kurs4

### 2. Создание виртуального окружения
python -m venv .venv
.venv\Scripts\activate  # для Windows

### 3. Установка зависимостей
pip install -r requirements.txt

### 4. Настройка базы данных PostgreSQL
Создай базу данных в PostgreSQL:
CREATE DATABASE kurs4;

### 5. Настройка переменных окружения
Создай файл .env в корне проекта:
SECRET_KEY=твой_секретный_ключ
DEBUG=True
DATABASE_NAME=kurs4
DATABASE_USER=postgres
DATABASE_PASSWORD=твой_пароль
DATABASE_HOST=localhost
DATABASE_PORT=5432

### 6. Применение миграций
python manage.py makemigrations
python manage.py migrate

### 7. Создание суперпользователя
python manage.py createsuperuser

### 8. Настройка Redis для кэширования
Установи Redis локально или используй Docker:
docker run -d -p 6379:6379 --name redis redis

### 9. Запуск сервера
python manage.py runserver

Сайт будет доступен по адресу: http://127.0.0.1:8000/

/messages/ - список сообщений

/admin/ - админ-панель

## Группы и права

### Группа "Managers" (Менеджеры)
Права:
- Просмотр всех клиентов, сообщений и рассылок
- Просмотр списка пользователей
- Блокировка/разблокировка пользователей
- Отключение рассылок (изменение is_active)

### Обычные пользователи
Права:
- Управление только своими клиентами, сообщениями и рассылками
- Просмотр личной статистики

## Кэширование
- Главная страница кэшируется отдельно для каждого пользователя
- Списки клиентов, сообщений и рассылок кэшируются
- Время кэширования: 5 минут
- Автоматическая очистка при создании/изменении/удалении объектов
