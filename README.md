# Интернет-магазин

Проект интернет-магазина, разрабатываемый в рамках курса. Проект будет постепенно дорабатываться с добавлением нового функционала.

## Структура проекта

- `mailing/` — основное приложение для работы рассылки.
- `users/` 

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/rahimzhanov/django-project-dz
cd <название-папки-проекта>
```
2. Создание и активация виртуального окружения
```
python -m venv venv
venv\Scripts\activate     # для Windows
```
3. Установка зависимостей
```commandline
pip install -r requirements.txt

pip install -r requirements.txt
```
4. Применение миграций

````python manage.py migrate````
5. Запуск сервера разработки
```
python manage.py runserver
```
После этого проект будет доступен по адресу: http://127.0.0.1:8000/
### Основные страницы
Главная страница (/ или /home/) — домашняя страница магазина.

Контакты (/contacts/) — страница с контактной информацией и формой обратной связи.

### Используемые технологии
```
Python 3.11+

Django 4.2+

Bootstrap 5 (для стилизации)

SQLite (на этапе разработки)
```
### Разработка
Проект ведётся с использованием GitFlow. Основные ветки:

main — стабильная версия

develop — ветка для интеграции новых функций

Функциональности разрабатываются в отдельных ветках, например feature/homepage
